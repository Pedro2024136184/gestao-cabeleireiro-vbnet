# Sistema de Gestão de Salão de Cabeleireiro - VB.NET (Windows Forms)

![VB.NET](https://img.shields.io/badge/VB.NET-.NET_Framework-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)
![Windows Forms](https://img.shields.io/badge/GUI-Windows_Forms-0078D7?style=for-the-badge&logo=windows&logoColor=white)
![Visual Studio](https://img.shields.io/badge/IDE-Visual_Studio-5C2D91?style=for-the-badge&logo=visualstudio&logoColor=white)

Aplicação desktop completa desenvolvida em **Visual Basic .NET (VB.NET)** com interface gráfica em **Windows Forms**, concebida para a gestão integrada e agendamento de atendimentos num salão de cabeleireiro e estética. Desenvolvida no âmbito da unidade curricular de **Linguagens de Programação (LP)**.

---

## 📋 Módulos e Funcionalidades

- **Gestão de Clientes:**
  - Registo, listagem, atualização de dados cadastrais e remoção de clientes.
  - Histórico de serviços requisitados por cada cliente.

- **Agendamento de Serviços:**
  - Marcação de novos atendimentos com seleção de cliente, profissional, tipo de serviço, data e hora.
  - Consulta de calendário e cancelamento de marcações.

- **Gestão de Áreas & Categorias:**
  - Parametrização das diferentes áreas do salão (ex.: Cabelo, Barba, Tratamentos, Manicure).
  - Categorização dinâmica de serviços com preços e durações estimadas.

- **Gestão de Fornecedores & Inventário:**
  - Registo e acompanhamento de parceiros comerciais e fornecedores de produtos cosméticos.

- **Interface Intuitiva (Windows Forms):**
  - Janelas modais especializadas para cada operação (adicionar, consultar, editar, apagar).
  - Validações de entrada de dados para garantir consistência operacional.

## 🚀 Como Compilar e Executar

### Pré-requisitos
- Sistema Operativo Windows 10 ou 11
- [Visual Studio 2019 ou 2022](https://visualstudio.microsoft.com/) com a carga de trabalho de **"Desenvolvimento para desktop com .NET"** instalada.

### Execução

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/Pedro2024136184/gestao-cabeleireiro-vbnet.git
   cd gestao-cabeleireiro-vbnet
   ```

2. **Abrir a solução:**
   - Faça duplo clique no ficheiro `Project_Cabeleireiro.sln` para abrir no Visual Studio.

3. **Compilar e Iniciar:**
   - Certifique-se de que o modo de configuração está em `Debug` ou `Release`.
   - Prima `F5` ou clique no botão **Iniciar** no Visual Studio para compilar e iniciar a aplicação desktop.
